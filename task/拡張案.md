## 2. 公式HP・事務所HPからの情報自動取得設計案

### 実装イメージ
1. **推し登録時のメタデータ拡張:**
   `favorites` テーブルに `official_url` (公式HP・ブログ等のURL) を保存。
2. **毎朝の自動バッチ処理:**
   - `official_url` が登録されている場合、Jina Reader (`https://r.jina.ai/[official_url]`) または Firecrawl でページの「News / What's New」セクションをテキスト化。
   - Gemini API にテキストを入力し、「直近24時間以内の新しいお知らせ」が存在するか判定・要約。
   - 新着があれば `news` テーブルへ保存。

- **Push通知機能 (Expo Notifications / Web Push):**

- **AI要約トーンのカスタマイズ:**
  「ファン目線の熱量高めな要約」「簡潔な箇条書き要約」「ビジネスライクな要約」などのトーン切替機能。
