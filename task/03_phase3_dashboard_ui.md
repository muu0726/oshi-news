# Phase 3: メインダッシュボード & ニュース表示 UI

## 概要
ユーザーが登録した「推し」ごとの動的タブ切替、および各人物の最新ニュース（AI要約付き）を閲覧できるメインダッシュボード画面を構築します。スマートフォンの操作感を重視したレスポンシブデザインとスムーズなアニメーションを盛り込みます。

---

- [x] モバイル対応のヘッダー・タブナビゲーション・レスポンシブコンテナ構築

- [x] `components/FavoriteTabs.tsx` の作成

- [x] タブ末尾の「＋ 推しを追加」ボタン (登録モーダルを開く) ＆ ホバー時削除ボタン
